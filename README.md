1. Pengertian JavaScript dan kegunaannya 
JavaScript adalah bahasa pemrograman yang digunakan untuk membuat halaman web menjadi interaktif dan dinamis. Kegunaannya antara lain untuk memvalidasi form, menampilkan pesan, merespons klik tombol, dan mengubah konten halaman tanpa harus memuat ulang seluruh halaman.
2. Pengertian jQuery dan kegunaannya 
jQuery adalah library JavaScript yang mempermudah penulisan kode JavaScript. jQuery digunakan untuk memanipulasi elemen HTML, menangani event seperti klik tombol, membuat efek animasi, dan melakukan permintaan AJAX dengan kode yang lebih sederhana.
3. Perbedaan JavaScript dan jQuery 
Perbedaan JavaScript dan jQuery adalah JavaScript merupakan bahasa pemrograman, sedangkan jQuery merupakan library yang dibuat menggunakan JavaScript. JavaScript dapat digunakan secara langsung tanpa library tambahan, sedangkan jQuery perlu dihubungkan ke halaman web sebelum digunakan. JavaScript terkadang membutuhkan kode yang lebih panjang untuk memanipulasi elemen HTML, sedangkan jQuery menyediakan fungsi yang lebih sederhana dan ringkas. Keduanya dapat digunakan untuk membuat halaman web menjadi interaktif dan dinamis.
